# Functions of king.masm that are replaced by C++ code.
#
#   label        C++ function, as the linker names it    group
#
# A label can also be the old label of a PROC that applySymbols.py renamed
# (it stays in the PROC's comment), or an address.
#
# The build (tools\kingasm.py gen) takes the function out of king.masm and
# points its label at the C++ function, so every call, jump and vtable entry
# that uses the label reaches the C++ code. It refuses a function that can't
# be taken out on its own, and one whose ret N doesn't match the C++
# parameters (__fastcall @Name@N removes N-8 bytes, __stdcall _Name@N removes
# N, a plain _Name is __cdecl and removes none).
#
# nmake ASM=<group, label or address,...> keeps the given functions in
# assembly; nmake ASM=all builds without any C++ code.
# main loop: src\mainloop.cpp
?Run@CWinApp@@UAEHXZ  @CWinApp_Run@8  mainloop    # CWinApp::Run ($L_63267d, MFC)
$L_5dd440    @CGameApp_OnIdle@12      mainloop    # CGameApp::OnIdle
$L_5e1af0    @CGameApp_Frame@8        mainloop    # CGameApp::Frame
$L_5e2040    @CGameApp_RunFrame@8     mainloop    # CGameApp::RunFrame
$L_569650    @CKingApp_Frame@8        mainloop    # CKingApp::Frame
